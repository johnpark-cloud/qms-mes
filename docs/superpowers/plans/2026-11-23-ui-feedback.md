# 화면 피드백 묶음 (2026-11-23)

사용자 피드백: "보기 불편하다", "한 눈에 안 들어온다", "조악하다", "전문적이지 못하다". 최하위 화면부터 최상위까지 전수 확인하며 적용한다. 옛 관리 화면이 뜨는 곳은 전부 새 화면으로 옮긴다.

## 사용자 결정

- 프로젝트: 고객사(거래처) 아래 프로젝트, 프로젝트마다 제품(품목)이 다르다. 공정(라우팅)·검사기준서·관리계획서는 제품 단위이므로 품목 → 프로젝트로 묶어 본다.
- 4M: 진행 단계·고객 승인 상태 드롭다운을 두되 사내 「승인 완료」는 비밀번호 서명으로만 된다(핵심 규칙 유지).
- 문서: 앱 안 본문 편집기(새 의존성 없음). 승인된 개정은 본문 잠금, 새 개정은 이전 본문을 복사해 고친다. 원본 파일 첨부도 유지.
- 사용자: 조직도·인원·인사 정보·역할·계정 상태를 새 화면으로. 시스템 관리자만 바꾸고 서버에서 검사. 비밀번호 초기화·관리자 권한 부여는 관리자 비밀번호 재입력. 삭제 대신 비활성(이력 보존). (보안 변경 승인됨)
