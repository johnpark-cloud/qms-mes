# 4차 고도화 구현 계획: 부적합 · 통합 화면 · CI 디자인 · 현장 메모 · 연차/급여 · 위젯 대시보드

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 설계 문서 G1~G14를 기존 Django 관리 화면 기반 QMS+MES 위에 구현한다.

**Architecture:** 기존 앱 구조를 유지한다.
- `core`: MES, LOT, 부적합, 공통 화면.
- `qms`: 품질 기능.
- 새 앱 `personal`: 연차·급여. 화면은 관리 화면 + 몇 개의 직접 만든 화면(htmx)으로 구성한다.
- 모든 화면은 `templates/admin/base_site.html` 한 틀을 상속하므로, 셸바·사이드바·검색창은 이 틀 하나에서 바꾼다.

**Tech Stack:** Python 3.12, Django 6.1.2, django-simple-history 3.13, openpyxl, whitenoise, waitress, htmx 2.0.4(동봉 `core/static/htmx.min.js`). SQLite(`data/db.sqlite3`).

**Spec:** `docs/superpowers/specs/2026-10-27-nc-ux-design.md` — 각 태스크의 "Spec §"는 이 문서의 절이다. 구현 전 해당 절을 읽는다.

## Global Constraints

- **새 의존성 추가 금지.** `requirements.txt`는 바뀌지 않는다.
  - Pillow가 없으므로 사진은 `FileField` + 확장자·크기 검증으로 받는다.
  - PDF는 인쇄용 HTML을 브라우저에서 "PDF로 저장"하는 방식이다.
  - ZIP은 stdlib `zipfile`을 쓴다.
- 인터넷 없이 동작해야 한다. 외부 CDN·폰트·아이콘은 쓰지 않는다.
- 화면 문구·오류 메시지·verbose_name은 모두 **한국어**로 쓴다.
- 회사 자산은 `settings.DATA_DIR`(= `data/`, git 제외) 아래에 둔다.
  - 로고: `DATA_DIR/brand/logo.(svg|png|jpg)`.
  - 첨부: `MEDIA_ROOT = DATA_DIR/media`.
- CI 색은 `#2C4D80`이다. 텍스트 대비는 라이트·다크 모두 WCAG AA 4.5:1 이상이어야 한다. 상태색(positive/critical/negative)은 의미를 유지한다.
- 기존 인터록은 약해지면 안 된다. 보류 → 투입·출하·실적 차단, 처분 규칙, 승인 잠금(`Approvable.save`) 모두 해당한다.
- 마이그레이션은 기존 행을 보존한다.
- 모든 기존 테스트가 계속 통과해야 한다.
  - 단위 테스트: `.venv\Scripts\python manage.py test` (현재 37개).
  - e2e: `.venv\Scripts\python scripts\e2e_check.py` (현재 55개).
- 태스크마다 테스트가 통과한 뒤 커밋하고 `git push`한다. 커밋 메시지는 한국어 Conventional Commits 형식이고, 끝에 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`를 붙인다.
- 지름길에는 `# shortcut: <한계>, <언제 바꿀지>` 주석을 단다. 코드 주석은 "왜"만, 한 줄로 쓴다.
- 시스템 관리자 = `user.is_superuser`다. 로그인은 필요하다. 승인 서명(`core.views.approve`, 부적합 MRB 암호)은 관리자도 암호를 입력한다.

## Review Focus

1. **바코드 스캐너 입력:** 앞뒤 공백, 끝의 줄바꿈, 대소문자 차이. 통합 검색과 간편 등록의 LOT 입력은 `strip()` 후 정확히 일치하는 값을 먼저 찾는다. Task 7과 Task 5에 테스트가 있다.
2. **아이폰 사진:** HEIC 파일, 10MB 초과 파일, 이미지가 아닌 파일. HEIC는 받고, 나머지는 한국어 오류로 거절한다. 이미 올린 다른 사진은 유지한다. Task 4에 테스트가 있다.
3. **다른 부적합의 보류와 겹치는 경우:** 부적합 A를 삭제하면 A가 만든 보류만 사라진다. 같은 LOT에 걸린 부적합 B의 보류는 그대로 남는다. Task 2에 테스트가 있다.
4. **수정 승인 후 저장 실패:** 수정 요청이 승인된 뒤 요청자가 저장하다가 검증 오류가 나면, 잠금 해제는 소모되지 않고 남는다. Task 2에 테스트가 있다.
5. **대시보드 배치 JSON 오류:** 위젯이 삭제됐거나, 권한이 없어졌거나, JSON이 깨진 경우. 해당 위젯만 조용히 빠지고, 깨진 JSON이면 기본 배치로 돌아간다. Task 13에 테스트가 있다.
