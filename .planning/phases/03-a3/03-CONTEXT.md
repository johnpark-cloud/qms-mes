# Phase 3 (A3) 맥락 — 끄기 전 열린 기록 검사와 종결 허용

## 결정

- **미결 #3 (2026-11-13 사용자: 혼자 쓰니 유연하게):** 수동 초품 해제 규칙은 만들지 않는다. 검사 모듈이 꺼져도 시스템 관리자는 검사 입력(`inspect/`, `api/qms/inspect/`)으로 판정할 수 있다. 4M이 검사를 requires로 두고, 열린 4M이 있으면 4M을 끌 수 없으므로 스위치로는 풀 수 없는 초품 차단이 생기지 않는다.
- **열린 기록(MOD-06)** `core/modules.py` `open_records`:
  - mes: 완료 아닌 작업지시
  - qms_inspection: 미판정 검사
  - qms_change: 승인됐는데 초품 합격 없는 4M
  - qms_capa·claim·supplier·audit: `closed_at` 비어 있음
  - qms_ppap: 미승인 제출
  - document·kpi: 없음
  - 켜진 모듈을 끌 때만 검사한다. 목록은 20건까지 보이고 나머지는 「외 n건」.
- **종결 허용(MOD-07)** `CLOSING`: 꺼진 모듈에서 시스템 관리자의 쓰기는 CAPA·클레임·SCAR·심사(지적 포함) 관리 화면 변경 폼과 검사 입력만 허용. 추가·삭제·그 밖은 403. 일반 사용자는 계속 404.
- **원인 표시(MOD-08)**: `[부적합] NC-…: L-1은(는) 보류 중이라 …`, `[4M 변경] CR-…: 초품 검사 합격 전이라 …`. 규칙은 그대로.
